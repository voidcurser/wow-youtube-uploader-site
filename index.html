WoW YouTube Uploader

WoW YouTube Uploader is a personal desktop application developed to automate uploading World of Warcraft gameplay recordings to YouTube.

Features

  • Detects new gameplay recordings.
  • Allows the user to customize video titles.
  • Generates custom video thumbnails.
  • Uploads videos to the user's YouTube channel.

Google Account Access

The application uses Google OAuth 2.0 to obtain authorization to upload videos to the user's YouTube channel.

The application is intended for personal use and is not offered as a public service.
