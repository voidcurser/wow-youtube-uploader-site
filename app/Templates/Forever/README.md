# Forever uploads

Choose **WoW Forever** in the **Game** selector at the top of the recording popup.
The popup remembers the game used for the last upload.

Forever uses the approved `JourneyTo60-v3.png` background, including the original
Blizzard logo with the accepted lighting and corner placement. Enter a video title
and optionally a description and a shorter thumbnail headline. The headline has
the same 60-character limit, three-line maximum and preview as general Retail videos.

The character list reads only `_forever_/WTF/Account` in the WoW installation.
Until your character is created and its settings are saved by WoW, you can leave
the character blank. A newly discovered character can be selected on the next
recording. Class/spec is optional free text; Retail specializations are not
automatically assigned. Forever remembers character/spec choices separately from Retail.

Forever uploads use its own gameplay description and `#WoWForever`, `#JourneyTo60`,
and `#WoWLeveling` hashtags. They do not receive Midnight or Mythic+ metadata.
Mythic+ dungeon/key fields are available only in Retail.

Both games upload as public and use the same upload retries and local file cleanup.
Background templates are preserved. Restart the uploader to load code changes.
